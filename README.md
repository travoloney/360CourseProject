# 360CourseProject

**Create your own branch before you start working on something.**

**Create a pull request when updating main to avoid breaking what we have so far.**

**Make sure to install the extension "live server"**
**To open the html right click the file and click Open with live server**

**To send drawing make sure to run the server by running node server.js in your console**
**You can open multiple tabs to send drawings between them**
